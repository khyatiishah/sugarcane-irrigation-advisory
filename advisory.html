How the Advisory Engine Decides

Recommendations come from a trained artificial neural network (a multi-layer perceptron), not a hand-coded rule table. It was trained offline in Python with scikit-learn on a synthetic dataset of 6,000 labeled field scenarios, and runs entirely in your browser — no server round-trip needed.

Model Architecture

8 input features → Dense(16, ReLU) → Dense(8, ReLU) → Dense(4, Softmax). Inputs: soil moisture, temperature, humidity, rain forecast, and one-hot encoded growth stage.

Training & Accuracy

Trained on an 80/20 train-test split with stratified sampling. Achieves 94.6% accuracy on held-out test data across 4 output classes.

In-Browser Inference

Trained weights are embedded in model_weights.js; ai_model.js reproduces scikit-learn's forward pass exactly, verified to match the Python model's output.
