About the Project

Background, objectives, and methodology of the AI & sensor-based irrigation advisory system for sugarcane.

Problem Statement

Sugarcane requires 1,500–2,500 mm of water over its crop cycle, making irrigation scheduling critical to yield and sucrose content. Traditional irrigation in most farms is based on fixed schedules or visual judgment, which frequently causes over-irrigation (wasting water and leaching nutrients) or under-irrigation (stressing the crop during sensitive growth stages). This project addresses that gap using low-cost sensors and an AI advisory layer.

Objectives

1. Real-Time Monitoring

Continuously measure soil moisture, temperature, and humidity across the sugarcane field.

2. Growth-Stage Awareness

Tailor irrigation thresholds to germination, tillering, grand growth, and maturity stages of sugarcane.

3. AI-Based Recommendations

Use sensor and weather data to generate irrigate/hold/delay recommendations and estimated water quantity.

4. Accessible Dashboard

Present recommendations through a simple web interface usable by farmers with minimal technical training.

Project Methodology

1. Requirement Analysis

Studied sugarcane water requirements at each growth stage and identified the key parameters (soil moisture, temperature, humidity, rainfall) needed for irrigation decisions.

2. Sensor Selection & Design

Selected capacitive soil moisture sensors, DHT22 temperature/humidity sensors, and a microcontroller (ESP32/Arduino) for field data acquisition — detailed on the Sensors & Tech page.

3. AI Advisory Logic

Built a rule-based decision engine (extendable to a trained ML model) that maps sensor readings and crop stage to an irrigation recommendation.

4. Web Interface Development

Developed this five-page website — Home, About, Sensors & Tech, AI Advisory demo, and Contact — using HTML, CSS, and JavaScript.

5. Testing

Verified navigation across all pages, cross-browser rendering, responsive layout on mobile, and correctness of advisory logic outputs across sample input ranges.

6. Deployment

Registered a project domain/subdomain and hosted the site on GitHub Pages for public access.
