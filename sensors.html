Sensors & Technology Stack

The hardware and software components that power real-time field monitoring and AI-based irrigation decisions.

Field Hardware

🌡️

Soil Moisture Sensor

Capacitive soil moisture probes placed at root depth (15–30 cm) measure volumetric water content, avoiding the corrosion issues of resistive sensors.

🌤️

Temperature & Humidity Sensor

DHT22/SHT31 sensors capture ambient air temperature and relative humidity, both of which affect crop evapotranspiration rate.

🌧️

Rain Gauge / Weather API

A tipping-bucket rain gauge or an external weather API supplies rainfall data and short-term forecasts to avoid unnecessary irrigation.

🔌

Microcontroller Node

An ESP32 or Arduino with a Wi-Fi/LoRa module reads sensor data and transmits it to the cloud at configurable intervals.

☀️

Solar Power Supply

A small solar panel with battery backup keeps field nodes powered independently in remote plots.

💧

Automated Valve (Optional)

A solenoid valve can be actuated directly by the advisory engine for fully automated drip irrigation control.

System Architecture

Data flows from field sensors through a gateway to cloud storage, where the AI advisory engine processes it and returns recommendations to the web dashboard.

[Soil / Temp / Humidity Sensors]
    ↓
[ESP32 Microcontroller + Wi-Fi/LoRa]
    ↓
[Cloud Database (e.g., Firebase / MQTT Broker)]
    ↓
[AI Advisory Engine — rule-based / ML model]
    ↓
[Web Dashboard & Farmer Alerts] → [Optional: Automated Valve]
